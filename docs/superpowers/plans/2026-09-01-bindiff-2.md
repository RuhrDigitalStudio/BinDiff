# BinDiff 2 implementation plan

1. Add failing tests for bounded ASCII/UTF-16 extraction, overlap, offsets,
   duplicates, empty data, and close benign inputs. Implement the Strings
   section and analyzer.
2. Add synthetic managed fixtures and failing tests for metadata-only assembly,
   reference, type, method, target-framework, and P/Invoke comparison. Implement
   the .NET section and analyzer with `PEReader`/`MetadataReader`.
3. Register both modules, validate their options, extend HTML detail tables, and
   expose CLI module names and string-length settings. Keep existing behavior
   compatible and test the complete report.
4. Add GUI toggles and dedicated tabs for .NET metadata and strings. Run focused
   theme/build tests and visually inspect a synthetic result.
5. Rewrite public documentation around real investigation workflows, add release
   metadata and CI/tag packaging, then run build, test, format, CLI, GUI, report,
   and tracked-file release gates.
